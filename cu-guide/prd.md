# PRD: C:U 상태이상 응급 매뉴얼

> 버전: v1.0 (첫 버전)
> 작성일: 2026-11-25
> 개발 도구: Claude Code

---

## 1. 개요

### 1.1 한 줄 설명
게임 **Casualties: Unknown** 플레이 중 상태이상이 생겼을 때, 그것이 무엇인지 빠르게 찾고 **무엇부터 어떻게 치료할지** 알려주는 개인용 가이드 웹페이지.

### 1.2 만드는 이유
- 이 게임은 상태이상 종류가 많아서 플레이 중에 바로 기억하기 어렵다.
- 위키에는 상태이상이 하나씩 따로 설명되어 있어, **여러 개에 동시에 걸렸을 때 무엇부터 해야 하는지** 한눈에 보기 어렵다.

### 1.3 사용자
- 나 혼자 사용 (내 컴퓨터에서 실행)
- 게임을 하면서 옆 창이나 옆 모니터로 띄워놓고 본다.

## 2. 범위

### 2.1 이번 버전에 포함하는 것
| 기능 | 설명 |
|---|---|
| 통합 검색 | 한국어 이름, 영어 이름, 증상 중 무엇을 입력해도 검색 |
| 아이콘 그리드 | 게임 속 아이콘과 같은 모양을 눌러서 찾기 |
| 상세 화면 | 증상, 치료법(아이템·행동) 보기 |
| 치료 순서 보기 | 걸린 상태이상을 여러 개 고르면 치료 순서대로 정렬해서 보여주기 |
| 출처 표기 | 화면 하단에 위키 출처 표시 |

### 2.2 이번 버전에 하지 않는 것
- 로그인 / 회원가입
- 데이터베이스(DB)
- 서버, 인터넷 배포(온라인 공개)
- 한국어/영어 전환 버튼
- 복잡한 치료 규칙 (예: "A가 있으면 B보다 먼저")
- 앱 안에서 내용 편집하는 기능 (내용 수정은 `data.js` 파일을 직접 고친다)

### 2.3 처음 넣을 데이터
- **흔한 부상 3~5개**만 먼저 넣는다.
- 내용은 Scav Prototype Wiki(scavprototype.wiki.gg)를 참고해서 **내가 직접 다시 써서** 넣는다.
- 개발 초기에는 형식만 맞춘 **임시(샘플) 데이터**로 만들고, 실제 내용은 내가 나중에 채운다.

## 3. 화면 구성

### 3.1 메인 화면 (찾기)
- **상단:** 앱 제목
- **검색창:** 입력하는 즉시 결과가 걸러진다 (검색 버튼 없이 실시간).
  - 검색 대상: 한국어 이름, 영어 이름, 증상
  - 영어는 대소문자 구분 없이 검색
- **아이콘 그리드:** 모든 상태이상을 아이콘 + 이름으로 바둑판처럼 보여준다.
  - 검색어가 있으면 그리드도 검색 결과만 보여준다.
  - 아이콘 이미지가 없으면 이름 첫 글자가 들어간 **회색 동그라미 임시 아이콘**을 보여준다.
- 각 항목:
  - 항목을 누르면 → 상세 화면으로 이동
  - **[+] 버튼**을 누르면 → "지금 걸린 상태이상"에 담기 (다시 누르면 빼기, 담긴 상태는 체크 표시로 구분)
- **하단 고정 바:** 1개 이상 담으면 나타난다.
  - 표시 예: `선택 3개 · 치료 순서 보기`
  - "전체 해제" 버튼 포함

### 3.2 상세 화면
- 이름: `출혈 (Bleeding)` 형식 (한국어 + 영어 원래 이름)
- 아이콘
- 우선순위 표시 (색 배지)
- **증상:** 목록 형태
- **치료법:** 필요한 아이템·행동 목록 형태
- [+ 담기] 버튼
- [← 돌아가기] 버튼

### 3.3 치료 순서 화면
- 담은 상태이상을 **우선순위 숫자가 작은 순서대로**(1이 가장 급함) 정렬해서 보여준다.
- 각 줄 형식: `① 출혈 (Bleeding) → 붕대 감기`
- 우선순위 숫자가 같은 항목은 같은 번호로 묶고 "동시에 처리"라고 표시한다.
- 항목을 누르면 상세 화면으로 이동
- [← 돌아가기] 버튼

### 3.4 공통
- 모든 화면 하단에 출처 표기: `참고: Scav Prototype Wiki (scavprototype.wiki.gg) · 비공식 팬 가이드`

## 4. 디자인

- **분위기:** 깔끔하고 단순하게. 흰 배경, 넓은 여백, 읽기 쉬운 글자 크기.
- **색 사용:** 우선순위만 색으로 강조한다.
  | 우선순위 숫자 | 의미 | 색 |
  |---|---|---|
  | 1 | 긴급 | 빨강 |
  | 2 | 빠르게 | 주황 |
  | 3 이상 | 여유 있음 | 회색 |
- **화면 크기:** PC 브라우저 기준. 옆 창으로 좁게 띄워도 깨지지 않게 한다(좁은 폭에서도 보기 좋게).
- 글꼴: 시스템 기본 글꼴 (외부 글꼴 불러오지 않음)

## 5. 기술 방식

### 5.1 사용 기술
- **HTML + CSS + JavaScript** (프레임워크, 라이브러리 사용하지 않음)
- 서버 없음. `index.html`을 **더블클릭하면 브라우저에서 바로 열린다.**

### 5.2 중요한 제약
- 파일을 더블클릭으로 열면(`file://`) 브라우저 보안 때문에 `fetch()`로 JSON 파일을 읽을 수 없다.
- 그래서 데이터는 **JSON 파일이 아니라 `data.js` 파일**에 JavaScript 변수로 넣고, `index.html`에서 `<script>` 태그로 불러온다.
- 외부 인터넷 연결 없이도 동작해야 한다.

### 5.3 폴더 구조
```
cu-guide/
├── index.html      ← 화면 구조
├── style.css       ← 디자인
├── app.js          ← 검색, 담기, 화면 전환, 정렬 동작
├── data.js         ← 상태이상 내용 (내가 직접 수정하는 파일)
├── icons/          ← 아이콘 이미지 (png)
└── prd.md          ← 이 기획서
```

### 5.4 데이터 형식 (`data.js`)
```javascript
const STATUS_EFFECTS = [
  {
    id: "bleeding",                 // 영어 소문자, 띄어쓰기 대신 하이픈(-)
    nameKo: "출혈",                  // 한국어 이름
    nameEn: "Bleeding",             // 게임 속 영어 이름
    icon: "icons/bleeding.png",     // 아이콘 경로 (없으면 "" 로 두기)
    priority: 1,                    // 치료 우선순위 (1이 가장 급함)
    symptoms: [                     // 증상 목록
      "증상 1",
      "증상 2"
    ],
    treatment: [                    // 치료법 목록 (아이템·행동)
      "치료법 1",
      "치료법 2"
    ],
    summary: "한 줄 요약 치료법"      // 치료 순서 화면에 보일 짧은 문장
  }
  // 상태이상을 추가할 때는 위 { } 묶음을 복사해서 쉼표(,) 뒤에 붙인다.
];
```
- `data.js` 맨 위에 **새 상태이상 추가하는 방법**을 한국어 주석으로 적어둔다.

### 5.5 화면 전환 방식
- 한 페이지(`index.html`) 안에서 JavaScript로 화면을 바꿔 보여준다.
- "담은 상태이상" 목록은 페이지 안에서만 기억한다 (새로고침하면 초기화되어도 괜찮다).

## 6. 완성 기준 (체크리스트)

- [ ] `index.html`을 더블클릭하면 인터넷 없이 정상적으로 열린다.
- [ ] "출혈", "bleeding", "BLEED", 증상 단어 중 무엇으로 검색해도 해당 항목이 나온다.
- [ ] 아이콘 이미지가 없는 항목은 임시 아이콘이 보인다.
- [ ] 항목을 누르면 상세 화면이 나오고, 돌아가기가 된다.
- [ ] [+]로 여러 개를 담으면 하단 바에 개수가 표시된다.
- [ ] 치료 순서 화면에서 우선순위 숫자 순서대로 정렬된다.
- [ ] 우선순위가 같은 항목은 묶여서 "동시에 처리"로 표시된다.
- [ ] `data.js`에 항목을 하나 추가하면 코드 수정 없이 앱에 나타난다.
- [ ] 브라우저 창을 좁혀도 화면이 깨지지 않는다.
- [ ] 모든 화면 하단에 출처가 표시된다.

## 7. 개발 단계 (Claude Code에 한 단계씩 요청)

한 번에 모두 만들지 않고, 단계마다 결과를 확인한 뒤 다음으로 넘어간다.

| 단계 | 할 일 | 확인할 것 |
|---|---|---|
| 1 | 폴더 구조와 `data.js`(샘플 데이터 3개) 만들기 | 파일이 모두 생겼는지 |
| 2 | 메인 화면: 아이콘 그리드 + 임시 아이콘 | 더블클릭으로 열었을 때 목록이 보이는지 |
| 3 | 상세 화면 + 돌아가기 | 항목 클릭 시 내용이 바뀌는지 |
| 4 | 통합 검색 | 한글·영어·증상 검색이 되는지 |
| 5 | [+] 담기 + 하단 바 | 개수 표시, 전체 해제가 되는지 |
| 6 | 치료 순서 화면 | 정렬과 "동시에 처리" 묶음이 맞는지 |
| 7 | 디자인 다듬기 + 출처 표기 | 창을 좁혀도 깔끔한지 |
| 8 | 실제 내용 채우기 (내가 직접 `data.js` 수정) | 6장 체크리스트 전체 통과 |

**요청 예시:**
> `prd.md`를 읽고 7장의 1단계만 진행해줘. 끝나면 무엇을 만들었는지 쉽게 설명해줘.
